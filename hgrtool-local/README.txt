HGRTool, local copy (no server needed)
=====================================
Double-click hgrtool.html (Chrome, Edge, Brave or Firefox). Everything runs in the page; nothing is uploaded.
Original: https://github.com/fadden/HGRTool by Andy McFadden (code Apache-2.0, images/docs CC BY-SA 4.0).
Rebuilt by tools/bundle_hgrtool.py because the original needs a web server (ES modules) and an internet icon font.
Open: raw 8192-byte Apple II hi-res screens (e.g. src/art/title/title_draft.hgr). Save As: a raw .hgr screen.
